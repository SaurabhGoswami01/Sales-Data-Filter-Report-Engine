# Sales Data Filter & Report Engine

## Project Overview
The Sales Data Filter & Report Engine is a Python-based project that analyzes sales data, filters records based on different conditions, and generates useful sales reports.

## Features
- Sales revenue calculation
- Overall sales summary
- Product-wise sales analysis
- City-wise sales analysis
- Category-wise sales analysis
- Filter sales by city, product, and category
- Filter sales by date and date range
- Identify top-selling products
- Display the top 5 sales records
- Export filtered reports to CSV
- Visualize sales data using charts

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset
The project uses a sample sales dataset containing:
- Date
- Product
- Category
- Quantity
- Price
- City
- Total Sales

## How to Run
1. Download `Sales_Data_Filter_Report_Engine.ipynb`.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the notebook.
4. Run the code cells in order.
5. View the generated reports and charts.

## Sample Results
- Total Revenue: Rs. 279,000
- Total Orders: 10
- Average Order Value: Rs. 27,900
- Top Product by Revenue: Laptop
- Top City by Revenue: Pune

## Project Purpose
This project demonstrates basic data analysis, data filtering, report generation, CSV export, and visualization using Python.
